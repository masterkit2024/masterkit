# Cartoon 3D video: фирменный стиль для роликов на любую тему

Скилл делает вертикальные ролики 1080x1920 (финал 1440x2560), 30 fps, любой длины: от 5-секундного клипа до 70-секундного рассказа.
Стиль: плоские 2D-персонажи («бобы» с палочками-руками и сливовой обводкой) в нарисованном 3D-мире с чёрными контурами, насыщенным небом, мягким размытием фона и плавной камерой. Всё считается кодом, AI-видеомодели не нужны.

**Как выглядит стиль:** открой `references/STYLE_SHEET.jpg`, `references/CHARACTERS.jpg`, `references/FACES.jpg` и папку `references/frames/`. Это эталон. Каждый новый ролик должен выглядеть так же, меняются только тема, место, герои и сюжет.

## ГЛАВНОЕ ПРАВИЛО (читать первым)
1. Картинку делаем ТОЛЬКО движком из `templates/engine/` (three.js + Remotion + наш пост-процесс). Не писать ролик заново «с нуля», не делать его на CSS/SVG/Canvas-2D/Manim/After Effects, не генерировать AI-видео, не менять стиль. Если тянет «сделать проще», нельзя: стиль держится на движке.
2. Новый ролик = новый файл `src/videos/<имя>/video.ts` (копия примера `templates/videos/timemachine/video.ts`). Движок (`src/engine/*`) не переписываем; если нужно новое умение (новый предмет, эффект, поза), добавляем функцию рядом, не ломая старые.
3. Перед показом пользователю обязательно рендерим стоп-кадры и сравниваем их с `references/frames/`. Если кадр не похож на эталон (нет чёрных контуров, плоские персонажи без обводки, серое небо, пустой голубой кадр), это ошибка: чини, а не отправляй.
4. Сюжет, персонажи и текст всегда свои. `references/reports/` и `STYLE_BIBLE.md` нужны только для изучения стиля (измерения референса). Не копировать чужие сценарии и кадры, не называть референсный канал.

## Порядок работы

### Если пользователь прислал сценарий и описание сцен (основной режим)
Сразу Этап 0, потом Этап 3. Темы и сценарий не предлагать: работаем по его тексту.
- Озвучку пришлёт или нет: спроси один раз, если не ясно. Без голоса длительность сцен берём из его описания (или ~3.5 слова/с текста, если текст есть) и делаем ролик без голоса: музыка + эффекты или тишина, как скажет.
- Если в описании чего-то не хватает (время суток, сколько людей, кто главный), выбери сам по смыслу и коротко напиши, что выбрал. Не останавливайся ради мелочей.

### Если пользователь просит придумать ролик
**Этап 1. Пять тем.** Ровно 5 тем, разные жанры (история, физика, природа, еда, техника, фантастика). Для каждой: рабочее название; хук одной фразой (парадокс как факт, 10-16 слов); 3-4 кадра, которые легко нарисовать в стиле; причина и следствие + бытовая аналогия; источники для проверки. Ключевые факты проверь поиском. Стоп, жди выбора.

**Этап 2. Сценарий для озвучки.** Полная проверка фактов (даты, числа, имена, места), источники в начале `SCRIPT.md`. Текст: язык озвучки (спроси, если не сказал); только то, что произносится, по предложению на строку; числа словами; 55-70 с ≈ 180-250 слов (3.2-3.7 слова/с). Формула: хук-парадокс → место и время → 3-4 шага эскалации → «щёлк» → сухая двойная реплика («Повезло... / Не повезло...») → объяснение через бытовую аналогию → следствие → ироничная концовка, возвращающая к началу. Не пересказывать то, что видно на экране. Под текстом: какие материалы (фото, логотипы) прислать. Стоп, жди озвучку.

Голос скилл не синтезирует: озвучку записывает и присылает пользователь (mp3/wav). Kokoro в режиме синтеза не запускать.

### Этап 0. Проект (один раз на компьютер или облако)
```bash
bash <skill>/templates/scripts/setup.sh ~/cartoon-project <имя_ролика>
cd ~/cartoon-project
node scripts/stills.mjs TimeMachine out/test_ 40,140,225 0.5
```
Сравни `out/test_*.jpg` с `<skill>/references/frames/timemachine/tm_40.jpg`, `tm_140.jpg`, `tm_225.jpg`: они должны совпасть. Если совпали, окружение рабочее. Если кадр пустой или голубой, смотри «Известные проблемы».

### Этап 3. Сборка ролика
1. **Тайминги.** Есть озвучка: `python audio/voice_kokoro.py - voice --audio <файл>` (только распознавание через faster-whisper) даёт `voice/voice.wav` (48 кГц моно) и `voice/words.json` `[{"w","s","e"}]`. Поправь ошибки распознавания вручную. Без озвучки: таблица сцен с длительностями. Длина ролика = голос + 0.5-1 с хвоста.
2. **Раскадровка.** Распиши сцены пользователя в шоты: на каждую сцену 1-3 шота по 1.5-4 с. На каждый шот: место, свет, кто в кадре и что делает, камера (общий / средний / крупный, движение), размытие, переход. Запиши таблицей в `SHOTS.md` и коротко покажи пользователю, если ролик длинный.
3. **Код.** `src/videos/<имя>/video.ts` по образцу примера (раздел «Как описание сцены превращается в код»). Зарегистрируй в `src/Root.tsx`:
   ```tsx
   import { SPEC as MY } from "./videos/<имя>/video";
   const My = makeVideo(MY);
   <Composition id="MyVideo" component={My.Component} durationInFrames={My.frames} fps={30} width={1080} height={1920} />
   ```
   Затем `npx tsc --noEmit`.
4. **Материалы пользователя** кладём в `public/materials/` (раздел ниже).
5. **Проверка кадров.** `node scripts/stills.mjs MyVideo out/<имя>/x_ <по 2 кадра на шот> 0.5`, смотри каждый кадр сам и сравни с `references/frames/`. Исправляй: камера внутри дома, предмет закрывает лицо, герой обрезан краем кадра, пустой кадр, нет контуров, неверные цвета. Повторяй, пока все кадры чистые.
6. **Звук** (раздел ниже), только когда тайминги картинки зафиксированы.
7. **Рендер.** `bash scripts/render.sh MyVideo out/<имя>/video.mp4` (1080x1920; финал 2K: добавь `--scale 1.3333`). Со звуком: `ffmpeg -i video.mp4 -i mix.wav -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k final.mp4`. Без звука: `ffmpeg -i video.mp4 -an -c:v copy final.mp4` (Remotion пишет пустую дорожку).
8. **QA.** `python scripts/short_qa.py final.mp4 out/<имя>/qa shots.json` (чёрные, белые, замершие кадры, громкость). Исправь найденное.
9. Отправь пользователю mp4 и в 3-5 строках: что в ролике, что выбрал сам, что можно поменять.

Сохраняй работу после каждого шага (коммит/копия). Первая версия может быть проще эталона: улучшение отдельным проходом после просмотра.

## Как описание сцены превращается в код
Весь ролик это один объект `VideoSpec` в `video.ts`:
```ts
export const SPEC: VideoSpec = {
  frames: 240,                         // длина в кадрах (30 fps)
  build: (s) => { ... },               // декорации: строятся один раз, общие для всех шотов
  kicks: [[4.6, 1.2]],                 // толчки камеры на ударах: [секунда, сила 0.5-1.6]
  shots: [ { a: 0, b: 80, light: "day", cams: [...], dof: {...}, cast: (t, f, cam, out) => {...}, animate: (t, f, n) => {...} }, ... ],
};
```
| В описании сцены | В коде |
|---|---|
| **Место** (площадь, улица, поле, берег, комната, лаборатория, космос) | `build(s)`: `s.ground(s.mat.cobble() / grass() / planks() / stone() / water(), x0, x1, z0, z1)`, `s.street(x0, x1, z, yaw)` (ряд домов), `s.house(...)`, `s.prop("tree_oak" / "plant_bush" / "hedge" / "lantern" / "cart" / "stall-red" / "windmill" / "canoe" / "flower_redA"...)`, `s.box(mat, min, max)`, `s.geo(new THREE.CylinderGeometry(...), mat, at)`, `s.wall(...)` |
| **Особые предметы** (машина времени, ракета, котёл, трон) | собрать из коробок, цилиндров, сфер в `s.named_("имя", (b) => b.add(geo, mat, matrix), at)`, анимировать в `animate` (`n.имя.rotation.y = ...`) |
| **Надписи, плакаты, экраны, фото пользователя** | `s.card("имя", ширина_м, высота_м, at, rotY, "materials/photo.jpg")` или рисунок через `Pen` |
| **Время суток** | `light: "day"` (по умолчанию), `"golden"` (закат, контровое солнце, тёплое), `"night"` (луна, холодный синий). `sunAz`/`sunEl` поворачивают солнце для шота |
| **Персонажи** | `person(cam, t, out, { id, outfit, at: [x, 0, z], mode, expr, ... })` в `cast` |
| **Ходьба** | `const w = walkPath([[x0,0,z0],[x1,0,z1]], t, startSec, 1.4)` → `person(..., { at: w.at, mode: w.moving ? "walk" : "stand", dir: w.dir })`; `"march"` для строя |
| **Эмоции** | `expr`: `neutral`, `stern`, `grin`, `laugh`, `whistle`, `nervous`, `shock`, `relief`, `relief_open`, `dazed`, `pained`, `smile`, `smile_closed`, `lick`; смена эмоции в момент T: `expr: t >= T ? "shock" : "grin", swaps: [T]` (моргание прячет смену) |
| **Позы** | `mode: "stand" / "walk" / "march" / "sit" / "fall"`, `wave: 0..1` (поднятая рука), `look: -1..1` (куда смотрит), `facing: -1/1` (поворот 3/4), `tilt`, `headTilt`, `prop` (`"icecream"`, `"shako"`, `["hammer", 0..1]`), `scale` |
| **Эффекты** | `fx(out, ключ, cw, ch, (p) => fxBurst(p, u), at, w, h, { soft, flat })`: `fxBurst` (вспышка), `fxStars` (звёзды над головой), `fxPuff` (дым/пыль), `fxSplash` (брызги), `fxRing` (кольцо на воде/земле, `flat: true`), `fxNote` (ноты), `fxCreak` (скрип), `fxCloud`, `fxPlank`, `fxDrum`, `fxSign`. Ключ должен меняться с кадром анимации: `` `burst${Math.round(u*30)}` `` |
| **Камера** | `cams: [{ f, s: hold(pos, look, f0, { fov, roll, rate, punch }) }, { f, dur: 24, s: ... }, { f, cut: true, s: ... }]`; `dolly`, `zoom` (камера у стены), `pushK`, `rolled` |
| **Размытие** | `dof: { cInf: 12, focus: [x, 1.6, z] }` (фокус на глазах) или функция от кадра |
| **Переходы** | `flash: true` (белая вспышка 4 кадра в начале шота), `xfade: 8` (наплыв при смене места или времени) |

Подсказки по размерам: персонаж-взрослый ≈ 2.2 м в мире (голова ≈ 0.6 м), глаза на высоте ≈ 1.6 м; дома 7 / 8.4 / 9.8 м; общий план: камера в 10-16 м, `fov` 40-46; средний: 3.5-5 м, `fov` 36-40; крупный: 2-3 м, `fov` 32-36, фокус на глазах.

### Миры для разных тем (оставаясь в стиле)
- **Город любой эпохи:** `street`/`house` (стили 0-7: кирпич, крем, охра, терракота), брусчатка, фонари, лотки, деревья. Флаги и вывески только правильные для эпохи и страны.
- **Природа, деревня, поле:** `grass` до горизонта, деревья `tree_*`, кусты, `hedge`, `windmill`, `cart`, цветы. Туман сам растворяет даль в цвет горизонта.
- **Вода:** `s.ground(s.mat.water(), ...)` + `fxRing`/`fxSplash`; сложная река есть в `templates/videos/bridge/world.ts`.
- **Интерьер (лаборатория, комната, замок):** пол `planks`/`stone`, стены `s.wall(s.mat.facade(...) или s.mat.color(...))`, без потолка или с ним, `noClouds: true`, свет `day` с `sunAz` 60-120 через «окно». Камера не должна стоять внутри стены.
- **Будущее, космос, фантастика:** те же простые формы + `s.mat.metal()`, светящиеся детали `s.mat.glow(hex)` (только мелкие: кольца, лампы, экраны, они дают bloom), небо `night`. Не превращать всё в неон: палитра остаётся мультяшной.
- **Путешествие во времени / смена эпохи:** одна площадь, разные шоты: `day` → вспышка `flash` → `golden`/`night`, другие костюмы (`townsfolk`, `GUARD`, `MERCHANT`, `LADY`, `MODERN`), спрятать или показать предметы в `animate`.

### Готовые персонажи (`engine/toon.ts`)
`SCIENTIST`, `WORKER`, `MERCHANT`, `LADY`, `FARMER`, `GRANDPA`, `GIRL`, `KID`, `PARENT`, `GUARD`, `MODERN`, `RIFLEMAN`, `OFFICER`, `soldier(v)`, `townsfolk(v)`; цвет кожи `SKINS[0..3]`.
Свой персонаж = `{ ...PRESET, jacket, pants, hat: "hair" | "cap" | "tophat" | "bonnet" | "shako" | "shako_tall" | null, hair, cap, dress, moustache, build: "adult" | "stout" | "kid", skin }`. Новые шапки, причёски и предметы в руках добавляются в `toon.ts` (функция `hatOn`, тип `Prop`) в той же манере: плоская заливка, сливовая обводка `INK`, без бликов.

## Стиль (что делает картинку «той самой»; всё уже зашито в движок, не ломать)
- **Персонажи:** плоские карточки, всегда повёрнуты к камере; голова-боб (h/w ≈ 0.94, острая макушка, полный подбородок), высота ≈ 3.5 головы, руки и ноги палочки, кисти чёрные точки; сливовая обводка `#241726`, толще со стороны тени; без румянца и бликов в глазах; моргание каждые 0.5-2.3 с по 4 кадра; шаг 0.8 м, ступни стоят на земле, покачивание 3-7 %, наклон 1-7°. Под ногами плотная контактная тень, днём ещё мягкий хвост от солнца. Персонажей не обводит контур мира (слой `NOINK`), у них своя обводка.
- **Мир:** чёрный контур `#030303` по силуэтам и перепадам глубины (≈5 px вблизи → 3 px вдали при 1080x1920); двухтоновый свет (освещённая сторона тёплая, тень холодная сине-фиолетовая, никогда не чёрная); нарисованные HD-текстуры со швами; стены приглушённые (кирпич, крем, охра, терракота), не лимонные и не лиловые.
- **Свет:** `day` (солнце az 75 / el 48, небо `#3e7fd2` → горизонт `#b8d0ec`, туман = горизонт 25→300 м); `golden` (низкое контровое солнце, ключ `#FFB36B`, тени фиолетово-синие, персиковый горизонт, видимый диск солнца с ореолом); `night` (луна, холодный ключ, тени тёмно-синие, небо `#0e1b3d` → `#33497a`). Солнце задаётся относительно камеры и замораживается на шот.
- **Глубина:** размытие фона примерно на трети экранного времени: крупные 12-16 px, средние 10-12, общие планы резкие; фокус на глазах. Bloom только у светящегося (порог 1.0).
- **Камера:** жёсткие склейки только на больших скачках; остальное плавные глайды 18-40 кадров; на каждой паузе медленный наезд 0.15-0.35 %/кадр (на ударных словах ~0.6 %/кадр ~35 кадров); крен 4-5° на акцентах; удары = толчок 7 кадров с переменой знака; никакой «ручной» тряски; передний план (куст, телега, край стены) примерно в каждом третьем шоте, но не на лице.
- **Монтаж:** вспышка белым после хука, наплыв 6-8 кадров при смене места/времени, реакция на экране на 0-3 кадра раньше слова.
- **Цвет:** нейтральный tone map + цветокоррекция по пресету света; медиана яркости днём ≈ 0.57, без задавленных чёрных, насыщенное небо, лёгкая виньетка. Зерна нет.
- **Пост-процесс (порядок важен):** рендер → ink (контуры) → размытие (pre + main) → bloom → NEUTRAL tone map → grade, MSAA 4. Все пиксельные размеры масштабируются от высоты кадра / 1920.

## Материалы пользователя (фото, картинки, логотипы, видео)
- Клади в `public/materials/`, не перерисовывай и не меняй содержимое.
- Показывай так, чтобы вписывалось в стиль: рамка или газета в руках, плакат на стене дома, экран, фото на столе, карточка с чёрной обводкой (`s.card(...)`, слой `NOINK`).
- Фото реальных лиц не дорисовывать мультяшно и не подменять.
- Если материала нет, а сцена его требует, нарисуй простой предмет кодом и скажи, что можно прислать.

## Звук и музыка
- Скрипты в `audio/`: `timeline.py` (таблица событий), `sfx_gen.py`/`sfx.py` (синтез эффектов), `music.py`/`instruments.py` (партитура), `dsp.py`, `mix.py`. В `mix.py`/`timeline.py` зашиты длина и секции ролика про мост (`DUR`, `MUSIC_TARGET`): переписывай под новый ролик.
- Музыка оригинальная, инструментальная, под тему (марш, лёгкий джаз, тревожная, весёлая, «космос»). Пения нет; песню пользователь присылает сам.
- Эффекты привязаны к событиям: шаги, удары, вспышки, скрип, брызги, ноты; каждый на 0-3 кадра раньше события.
- Микс: голос как есть, музыка +3 дБ к стандарту, эффекты -6 дБ, музыка приглушается под речь по `words.json`, итог -15 LUFS, пик ≤ -1 дБ, 48 кГц, длина ровно как у видео.
- Ролик без голоса: музыка + эффекты (или тишина, если пользователь так сказал).

## Рендер: где и как
- `scripts/env.mjs` сам выбирает браузер и WebGL: на машине с видеокартой `angle`, в облаке без видеокарты `swangle` (программный рендер) и headless shell из Playwright. Переопределить: `GL=angle|swangle|egl`, `STYLE_BROWSER=<путь>`.
- Скорость: с видеокартой ~4 кадра/с (2K); в облаке без видеокарты ~4-8 с на кадр при 0.5 масштабе стоп-кадра и ~3-4 кадра/с параллельно при рендере mp4 1080p (10 с ролика ≈ 10-20 мин). Длинные рендеры запускай в фоне.
- Временные файлы: `REMOTION_TMP` (по умолчанию `.rtmp` в проекте); после рендера `render.sh` чистит бандлы.

## Известные проблемы и решения (проверено)
- **Пустой голубой кадр.** Причина: `<EffectComposer>` из `@react-three/postprocessing` с R3F 9 ничего не рисует. В движке свой composer (`Video.tsx`); не возвращай `<EffectComposer>`.
- **Нет моделей Kenney.** Не нужны: деревья/кусты/живые изгороди/флаги рисуются кодом в `build.ts`, остальные предметы кодом в `props.ts`. Если положить настоящие CC0-модели в `public/kenney/<имя>.glb`, движок возьмёт их.
- **Браузер падает «Socket path too long» / SIGABRT.** Использован полный Chrome с длинной временной папкой. `env.mjs` выбирает headless shell; не задавай `CHROME_PATH` на полный Chrome.
- **«Automatic fallback to software WebGL» в логе** это предупреждение, не ошибка (облако без видеокарты).
- **Версии пакетов** зафиксированы в `templates/project/package.json` (remotion 4.0.545, three 0.170, @react-three/fiber 9.8.2, postprocessing 6.39.6, react 19). Не обновляй без проверки стоп-кадрами.
- **Дом или предмет загораживает камеру.** Движок сам убирает дома и предметы с линии взгляда камер всех шотов (`setSight`). Но `s.box`/`s.geo`/`named_` не проверяются: ставь их сам вне кадра камеры.
- **Предмет ближе 2 м к камере** выглядит огромным пятном; куст, обрезанный краем кадра, читается как зелёный шар.
- **Качели** рисовать двумя верёвками к широкой доске. **Флаги** только правильные для эпохи и страны.
- **Пустая пауза = заморозка.** На каждой паузе нужен наезд (`hold` делает его по умолчанию).
- **Диск:** каждый бандл Remotion копирует `public/` во временную папку; держи `public/` маленьким, чисть `remotion-webpack-bundle-*`.
