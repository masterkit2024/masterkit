# Ролик «Как маньяки выбирают жертву» — исходники

Видео целиком собрано кодом: Canvas 2D в headless Chromium (Playwright) → JPEG-кадры → ffmpeg; звук (музыка + SFX) синтезирован в `sound.py`.

- `timeline.json` — абсолютные тайминги всех слов озвучки (выравнивание по паузам, `align.py`, `compose.py`).
- `lib.js` / `sets.js` / `engine.js` — движок: камера с параллаксом, зерно, виньетка, пыль, шторки 2.39:1, переходы (вспышка, смазка, лист бумаги, зум, глитч, затемнение), штампы, счётчики, карты.
- `scenes*.js` — 94 плана по раскадровке, привязаны к словам озвучки через `cue(сцена, 'фраза')`.
- `sound.py` → `music.npy`/`sfx.npy`, `mix.py` → `mix.wav`.

Медиа (фото, озвучка, шрифты Oswald/PT/Playfair из google/fonts) в репозиторий не кладутся — положить их в `assets/` и `a1..a8.wav`.

Рендер: `python3 -m http.server 8765` в этой папке, затем `node render.js video out.mp4 <кадр0> <кадр1>` (можно параллельно частями), склейка ffmpeg concat, затем mux с `mix.wav` + `loudnorm=I=-14`.
