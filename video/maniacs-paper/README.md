# «Как маньяки выбирают жертву» — версия 2 (бумажный коллаж по TZ.md)

Весь ролик собран кодом: Node + Skia (`@napi-rs/canvas`), без браузера.

- `core.js` — время, якоря к словам озвучки (`cue(сцена, 'фраза')`), камера с параллаксом.
- `paper.js` — материалы: текстура бумаги с волокнами, рваные края с белой сердцевиной, толщина листа, 3-слойные тени, полароиды (дуотон/растр), кнопки, скотч, штампы с растёкшимися чернилами, стикеры, буквы-вырезки, папки, конверты, силуэты.
- `sets.js`, `dioramas.js` — столы, пробковая доска, нить, маркер, машинка, счётчики на карточках, реквизит, ДНК-лента, карты-вырезки, вокзал, ночная улица, комната, обочина, океан.
- `engine.js` — планы, 11 бумажных переходов, motion blur (4 подкадра на кадр), плёночная постобработка (зерно, виньетка, хроматическая аберрация, пыль, мерцание).
- `s01.js … s8.js` — 95 планов по раскадровке; `audio.py` + `mix2.py` — синтез музыки A–H, звуковых эффектов, обработка голоса и микс.

Рендер: `npm i @napi-rs/canvas`, положить `fonts/` (Oswald, PT Mono, Caveat, Playfair Display), `photos/`, `voice_src/`, затем
`node run.js events ev.json`, `node run.js video part.mp4 <кадр0> <кадр1>` частями, склейка ffmpeg concat + `mix_full.wav`.
