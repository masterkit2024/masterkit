# Credits — «Школа креатива» (10 s cel / line-boil spot)

Everything in this film was made from scratch for this project; **no third-party assets are used**.

| Element | Source | Licence |
|---|---|---|
| All drawings (pencil, character «Клякса», FX, starbursts, smoke, sparks) | Procedural brush renderer in `film.js` (original code) | Original work |
| Hand-lettered Cyrillic title and tagline | Original stroke "font" drawn as centrelines in `film.js` (no font files) | Original work |
| Paper texture | Procedural seeded noise + fibres in `film.js` | Original work |
| Music and all SFX | Synthesised in `audio.py` (numpy/scipy, additive/modal synthesis, filtered noise) | Original work |
| Tools | Chromium + Playwright (Apache-2.0), ffmpeg (LGPL/GPL), numpy/scipy (BSD) | Used as tools only |

The brand «Школа креатива» is a fictional name used for this spot.
