# Персонажи мультсериала: Кеша, Лёня, Сугроб, Баба Глыба

Скил содержит готовый, проверенный риг четырёх персонажей в едином стиле (React + SVG, кадр 1080×1920) и инструменты превью/проверки. Задача — **использовать и расширять эти компоненты, а не рисовать героев заново**: так персонажи остаются узнаваемыми от ролика к ролику.

## Быстрый старт

1. Разверни риг в проект (папка — куда угодно, например `./cartoon`):
   ```bash
   bash <путь-к-скилу>/scripts/setup.sh ./cartoon
   ```
   Скрипт копирует `characters/`, `remotion/`, `preview/`, а если нет — `package.json`/`tsconfig.json`, и делает `npm install`. Уже существующие `characters/` не перезаписывает без `--force` (в них могут быть правки проекта).
2. Используй компоненты в любом `<svg>` или в композиции Remotion:
   ```tsx
   import { Kesha, Lenya, Sugrob, BabaGlyba } from './characters';
   <svg viewBox="0 0 1080 1920">
     <Kesha x={300} y={1700} scale={0.8} emotion="panic" mouth="wide" pose="panic" />
     <BabaGlyba x={760} y={1700} scale={0.6} rage mouth="o" />
   </svg>
   ```
   Пример композиции: `remotion/Root.tsx` → `RigDemo` (сцена — чистая функция от кадра в `remotion/scene.tsx`).
3. Проверь результат (см. «Проверка»).

## Справочники — читай по задаче

- `references/characters.md` — **библия персонажей**: внешность, характер, цвета, рост, что нельзя менять. Читай перед любой работой с внешним видом и перед постановкой сцены.
- `references/rig-api.md` — пропсы, углы суставов, позы, эмоции, рты, анимация в Remotion, как добавить новую позу/эмоцию/деталь. Читай перед анимацией и любыми правками кода.
- `examples/*.png` — эталонные листы (линейка роста, эмоции, рты, две формы Глыбы). Сверяй с ними свой рендер.

## Правила стиля (не нарушать)

- Контур один на всех: `OUTLINE = 6` px кадра, тёмный `palette.ink`, скруглённые концы и стыки. Толщина не зависит от `scale` — не масштабируй персонажа внешним `transform` поверх компонента, передавай `scale` пропсом (иначе контур поплывёт).
- Плоские цвета, одна тень на заливку (−15 %), **без градиентов и бликов**. Все цвета — только из `characters/palette.ts`.
- Никакого текста на персонажах и в кадре, если пользователь сам не попросил.
- Пропорции роста фиксированы: Кеша 100 % (1000 ед.), Лёня 70 %, Сугроб 130 %, Баба Глыба 125 %, «ГЛЫБА» 160 %. В одной сцене давай всем **одинаковый** `scale`, иначе рост перестанет быть честным.
- Рабочий масштаб 0.35–2. Мельче лица слипаются (контур постоянный), такой общий план лучше заменить другим кадром.
- Новые детали рисуй теми же средствами (`Shape`, `Tube`, `Line`, `Limb` из `parts.tsx`) — тогда стиль сохранится автоматически.

## Типичные задачи

- **Озвучка/липсинк:** меняй `mouth` по слогам (`closed` → `slight`/`wide`/`o`/`smile`), 2–4 кадра на форму при 30 fps; паузы — `closed`. Пример — `talk()` в `remotion/scene.tsx`.
- **Эмоция:** `emotion` управляет только глазами и бровями; рот задаётся отдельно. Для статичных кадров подходящий рот подсказывает `EMOTION_MOUTH`.
- **Движение:** готовые позы (`pose="wave"` и т. д.) + поверх них углы в `rig={{...}}`, или `lerpPose(a, b, t)` между двумя позами. Дыхание — `squash` ±1–2 %, прыжки/удары — `squash` с затухающим колебанием.
- **Превращение Бабы Глыбы:** переключение `rage` + короткий «пружинный» `squash`/`bodyY` на 10–15 кадров (пример в `scene.tsx`).
- **Поворот:** `facing="left"` зеркалит персонажа целиком.

## Проверка (обязательно после изменений)

```bash
npm run preview          # PNG-листы в previews/
node preview/check.cjs   # контур 6.00 px везде, никто не вылез за кадр, нет пересечений и обрезки
npm run video            # previews/rig-test.mp4 — покадровый тест анимации (без звука)
npm run typecheck
```
Открой получившиеся PNG и посмотри глазами: узнаваемость силуэта, читаемость лица, ничего не обрезано. Для роликов проверяй кадры из **готового MP4** (например, `ffmpeg ... -vf "select=...,tile=..."`), а не исходные SVG. Если что-то правил в `characters/`, сравни листы с `examples/`.
